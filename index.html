So nutzt du den XRechnung Konverter

Mit diesem Browser Tool wandelst du ZUGFeRD oder Factur X PDF Rechnungen mit eingebetteter XML direkt in eine gültige XRechnung um. Alle Schritte laufen lokal im Browser, die PDF bleibt auf deinem Gerät.

  1. PDF auswählen
    Öffne deine ZUGFeRD oder Factur X PDF und ziehe sie in das Feld Datei hierhin ziehen oder klicken oder wähle sie über den Dateidialog aus. Der Dateiname erscheint unter Ausgewählte Datei.
  2. Analyse starten
    Klicke auf In XRechnung umwandeln. Das Tool extrahiert die eingebettete XML und prüft, ob bereits eine XRechnung Guideline gesetzt ist. Falls nötig, kannst du Leitweg ID, Lieferantennummer und eine Käufer E Mail ergänzen.
  3. XRechnung speichern
    Nach einem kurzen Countdown wird die erzeugte XRechnung XML automatisch heruntergeladen. Speichere die Datei und nutze sie in E Rechnungsportalen von Behörden oder in deiner Buchhaltungssoftware.

Was macht dieses Tool?

Dieses Browser‑Tool wandelt ZUGFeRD‑ bzw. Factur‑X‑PDFs mit eingebetteter XML lokal in eine gültige XRechnung um. Du kannst die erzeugte XML direkt in E‑Rechnungsportalen von Behörden oder in kompatible Buchhaltungssysteme importieren.

Kurz erklärt

  • ZUGFeRD / Factur‑X: PDF mit eingebetteter XML‑Rechnung.
  • XRechnung: Standard für E‑Rechnungen an deutsche Behörden.
  • Lokal im Browser: Dateien werden nicht hochgeladen oder gespeichert.
